# React Native Modern Lab

A hands-on engineering laboratory for exploring modern React Native architecture, performance, native integration, and Mobile AI.

This repository is built through practical experiments rather than tutorials. Each experiment focuses on understanding how React Native works internally and validating the concept with a working implementation.

## What This Lab Covers

- Modern React Native architecture
- React Native New Architecture
- Fabric
- TurboModules
- JSI
- React Native Codegen
- Rendering and performance optimization
- React Native DevTools
- Metro
- Native iOS and Android integration
- Background native work
- Mobile AI and LLM integration
- Streaming AI responses
- Backend AI architecture
